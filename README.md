# DearU 🎂 — 异地恋专属生日蛋糕共创

让异地的两个人，隔着屏幕**一起做生日蛋糕、唱生日歌、吹蜡烛**的仪式感小产品。
纯前端单页应用，零后端零登录，**链接即分享**。

## ✨ 玩法（4 个阶段）

1. **选底胚** — 经典奶油 / 千层 / 慕斯 / 巴斯克 4 款
2. **双人装饰** — 奶油挤花涂鸦、拖放 🍓🫐🕯️、写祝福语、拖动调整、撤销、随时换底胚
3. **礼盒打包** — 生成接力链接（蛋糕状态压缩进 URL），发给对方打开就能继续画
4. **唱生日歌 · 吹蜡烛** — 暗夜火焰动画、合成生日歌 + 歌词高亮、**麦克风吹蜡烛**（点火焰兜底）、全灭后彩带许愿

## 🔗 协作机制

- 无角色区分：任何拿到链接的人权限完全相同，可反复来回接力
- 状态编码：`JSON → gzip → base64url → URL hash`，坏链接自动容错回首页
- 谁改完就再生成最新链接发回去即可

## 🛠 技术

- 单文件 `index.html`，Canvas 矢量绘制，Tailwind CSS CDN
- WebAudio 合成生日歌 / 麦克风吹气检测（HTTPS 下可用）
- 部署：GitHub Actions → GitHub Pages，push 即上线

## 🚀 本地运行

直接双击打开 `index.html` 即可；生成接力链接后的完整体验需部署到 HTTPS。

## 📦 部署

仓库 `Settings → Pages → Source` 选 **GitHub Actions**，之后 `git push` 自动部署到：

`https://yanmingzhang2000.github.io/DearU/`
